# 二维码工具（iOS 原生版）

盒码解密 + 二维码合集图生成，iPhone 原生 App。

## 功能

- 粘贴密文（每行一条）或选择多个 .txt 文件
- 本地解密：AES-128-ECB + PKCS7，Base64 密文 -> y2wm 链接
- 明文 http(s) 链接原样通过
- 每个文档生成一张二维码合集图（每码下方标注盒码尾号）
- 保存到相册 / 分享到微信、WhatsApp / 复制全部链接

## 密钥

- 密钥**不在代码里**，首次打开请在 App 内「设置」里输入 16 位密钥
- 密钥只保存在本机 iOS 钥匙串，不上传任何服务器
- 解密全部在手机本地完成，不联网
